# arma3_artillery_calc

Баллистический калькулятор артиллерии для компьютерной игры **Arma 3** (мод RHS).
По координатам орудия и цели считает дальность, азимут и возвышение для каждого подходящего заряда.

Орудия: **2Б11** (миномёт 120 мм), **2Б14** (миномёт 82 мм), **Д-30А** (гаубица 122 мм).
Таблицы перенесены из Android-версии приложения (`arma3calc_android`).

## Как считается

- Координаты в метрах карты: X на восток, Y на север, высота над уровнем моря.
- Дальность считается по горизонтали, азимут через `atan2`, в тысячных (6400 на круг).
- Возвышение линейно интерполируется между строками таблицы.
- Поправка на высоту: `возвышение − (высота цели − высота орудия) / 100 × поправка на 100 м`.
  Если цель выше, возвышение уменьшается; если ниже — увеличивается.
  У предельных дальностей поправки в таблицах нет, и интерфейс об этом предупреждает.

## Запуск

```bash
uv sync --all-extras
uv run uvicorn arma3calc.web.app:app --reload
```

Страница откроется на http://127.0.0.1:8000, документация API — на `/docs`.
На телефоне страницу можно добавить на домашний экран (PWA), но для расчёта нужен доступ к серверу.

Через Docker:

```bash
docker build -t arma3calc .
docker run -d --name arma3calc -p 8000:8000 --restart unless-stopped arma3calc
```

## Тесты

```bash
uv run pytest
```

## Структура

```
src/arma3calc/
  data/*.json     таблицы стрельбы, по файлу на орудие
  tables.py       загрузка и проверка таблиц
  solver.py       дальность, азимут, интерполяция, поправка на высоту
  web/app.py      FastAPI: /api/weapons, /api/solve, страница
  web/static/     интерфейс (одна страница без сборки)
tests/
```

Чтобы добавить орудие, положите в `data/` JSON такого же формата.
Строка таблицы: `[дальность_м, возвышение_mil, поправка_на_100м_высоты, время_полёта_с (необязательно)]`.
